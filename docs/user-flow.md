# User Flow

## 1. Open App

## 2. See a default hand filled in 
Pre-filled in hand open to a node (heads-up, probably a tough river situation), with poker tracker 4 style UI in left box mainly filling it up, on right side - colored "Action" (bet/raise/call/fold), with "Analysis" box underneath with textual anlysis

## 3. Click "Add a new hand"
Top right

## 4. Enter hand details
Items: (type of game, blinds, stack size, hero hole cards, actions at each street, villain hole cards - opt, additional information/notes).

Full-screen, with clear delineations of pre-flop, flop, turn, river. Very intuitive way to enter hole cards, like GTOWizard style. Automatically moves to next node.

## 5. Replay the hand, starting from pre-flop
Exits back out to viewer mode, with hand replay on left, analysis on right. Replayer should have right arrow for next action, left arrow for back action, shortcuts for pre-flop, flop, turn, river.

## 6. Hero decision
Read analysis for the decision, there should be clearly a "bet/raise, call, fold" recommendation and then coherent reasoning for it in analysis box under.


## 7. Reach end of hand / showdown
Should be full analysis of the entire hand, with like a scoring, and then post-mortem, and then recommendations/tips

## Not in V1
- Multiplayer scenarios
- importing hands from sites
- tournies / PLO / mixed games
- actual solver analysis (only LLM responses right now)
